# 浪漫满溢 · 原生微信小程序婚礼请柬（多租户版）

纯原生微信小程序（WXML / WXSS / JS）婚礼请柬：开屏信封、请柬与倒计时、爱情故事、婚纱相册、盛典日程与导航、宾客回执（RSVP）、祝福弹幕墙，以及新人专属管理后台（含婚礼二维码生成）。

**多租户**：一个小程序服务多对新人。通过**扫小程序码进入**（码里带 `wid` 婚礼标识）查看对应新人的请柬；没有扫码参数时展示平台推广页。后端在 Cloudflare Workers + D1（图片转存 ImgBB），客户端不含任何密钥。

## 快速开始

1. 微信开发者工具导入 `wxapp/` 目录（`miniprogramRoot` 已指向 `miniprogram/`）。
2. 「详情 → 本地设置」勾选 **不校验合法域名**。
3. 先启动后端：仓库根目录 `npm run dev`，并用
   `node scripts/create-wedding.mjs demo 测试新郎 测试新娘 --local` 建一场测试婚礼。
4. **调试进入方式**（二选一）：
   - 开发者工具「编译模式 → 添加编译模式」：启动参数填 `wid=demo`（推荐）；
   - 或在小程序里扫管理后台生成的二维码。
5. 后端地址仅一处可改：`utils/config.js` 的 `BASE_URL`。

## 多租户（扫码进入）说明

- 启动时解析小程序码 `scene`（或分享链接 `?wid=`）→ 进入对应婚礼；
- 没带 `wid` → 显示**推广页**（内置宣传样式，可用服务端 config 表 key=`promo` 定制文案/图片）；
- 带了 `wid` 但婚礼未创建 → 显示「该请柬不存在或未开通」；
- 转发请柬的分享卡片会自动带上 `wid`；
- 同一微信在不同婚礼里的昵称/电话/祝福/回执**各自独立**（后端 users 主键为 openid+wedding_id）。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `utils/config.js` | 后端地址唯一配置点（BASE_URL） |
| `utils/api.js` | 云端 API 封装（自动带 `wid`、登录、配置、相册、回执、祝福、二维码地址） |
| `utils/wechat.js` | 微信原生能力（拨号 / 地图导航 / 保存相册） |
| `pages/index` | 请柬（开屏火漆信封、倒计时、信笺；含推广页/失效页覆盖层） |
| `pages/story` | 爱情故事时间轴 |
| `pages/gallery` | 婚纱相册 |
| `pages/schedule` | 盛典日程、地图导航、一键拨号 |
| `pages/rsvp` | 宾客回执（按当前婚礼隔离） |
| `pages/blessings` | 祝福弹幕墙 |
| `pages/admin` | 管理后台（婚礼管理员鉴权 + 婚礼二维码生成） |

## 管理后台

- 入口：**长按首页新人姓名大标题**进入。
- 鉴权：当前账号需是**这场婚礼的管理员**（服务端 `users.is_admin=1`；由平台方创建婚礼时指定，或用 SQL 设置），或平台超管（`ADMIN_OPENIDS`）。无口令。
- 首次使用：
  1. 进入管理后台会显示「当前 OpenID」，复制；
  2. 交给平台方设为该婚礼管理员（或执行
     `UPDATE users SET is_admin=1 WHERE openid='…' AND wedding_id='…'`）；
  3. 下拉刷新即进入。
- 功能：宾客回执名单与统计、相册上传/删除、婚礼信息编辑、**我的婚礼二维码**（正式版/体验版/开发版码切换，长按保存到相册后转发给亲友）。

## 注意事项

- 微信官方「获取手机号」需企业主体认证的小程序；未认证时宾客可直接手动输入手机号（已有兜底）。
- 正式版发布要求 request / uploadFile 合法域名为**已 ICP 备案的自有域名**（workers.dev 不能直接添加）；开发与体验阶段使用工具「不校验合法域名」即可。
- 展示图片来自 ImgBB（`i.ibb.co`）不需要域名白名单；「保存图片到相册」用的 `wx.downloadFile` 需要 downloadFile 白名单，正式版该功能可能受限（仅影响保存）。
- 小程序码生成接口需要小程序在微信侧已有对应环境的版本；未发布前请先用开发者工具「编译模式」带 `wid` 调试。
