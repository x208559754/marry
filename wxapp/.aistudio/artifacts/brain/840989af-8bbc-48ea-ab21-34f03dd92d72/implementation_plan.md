# 浪漫满溢·电子结婚请柬与小程序H5互动系统

一款专为新人婚礼打造的沉浸式电子请柬 Web 应用。系统支持无缝嵌套在微信小程序 WebView、公众号、朋友圈与独立移动端浏览器中，兼具极致的浪漫视觉体验与强大的管理统计功能。

### User Review & Critical Decisions

> [!IMPORTANT]
> 针对您的核心需求与前期沟通，本次规划已全面整合以下关键设计决策，无需额外妥协：

- **全功能互动套件**：
  1. 旋律与浪漫动效：背景音乐（支持预置多首浪漫婚礼轻音乐与自定义音频）、黑胶悬浮唱片动效、浪漫花瓣/金箔飘落粒子动效。
  2. 甜蜜画卷：新人浪漫故事时间线、婚纱摄影画廊与全屏灯箱大图预览。
  3. 盛典指引：婚礼当天流程时间表、宴会厅高德/腾讯/百度地图导航与一键复制地址。

- **双端自适应与小程序专属优化**：
  - **移动端/小程序 WebView**：原生满屏沉浸体验，底部悬浮快捷触达栏（送祝福、出席回执、一键导航），符合微信生态触摸与分享习惯。
  - **桌面端访问**：智能双栏体验——左侧为真实 9:16 手机壳沉浸预览（可扫码在真机或小程序体验），右侧为全功能可视化编辑与回执数据看板。
- **独立管理与数据导出**：内置独立管理后台开关，支持修改新人姓名、婚期倒计时、宴席地址、照片替换、音乐配置，并可一键导出宾客回执 CSV 表格。

### 1. Overview & Core Concept

- **What It Does**: 提供一套集“浪漫展示”、“互动送福”、“出席回执”与“后台管理”于一体的现代化婚礼请柬 Web 应用，可直接作为独立网页运行，亦可直接嵌入微信小程序 Web-view 组件。
- **Target Audience / Persona**: 准新人夫妇（用于向亲朋好友分享婚礼喜讯并统计到场人数）以及受邀宾客（长辈、好友、同事，注重简单易懂的浏览与互动体验）。
- **Key Value**: 摆脱第三方模板平台强制广告、高昂付费或数据泄露的痛点，提供高自由度、零广告、高颜值的专属婚礼请柬，数据安全保存在本地。

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: 小程序嵌入与独立运行的完美兼容**
  - *Chosen Approach*: 采用全自适应设计（Mobile-First）。在手机和小程序 WebView 中自动充满屏幕，隐藏外层装饰；在电脑端大屏访问时，呈现“精美手机样机模拟器 + 实时管理控制台”双栏分屏，方便新人在电脑上从容编辑和导出名单。
  - *Why*: 真正解决“既要发给长辈在手机上看，又要自己在电脑上方便打字修图和看Excel”的双重场景。
- **Decision 2: 数据持久化与隐私安全**
  - *Chosen Approach*: 本地浏览器 `localStorage` 自动持久化 + JSON/CSV 导入导出备份。
  - *Why*: 零配置、零服务端门槛、无需绑定第三方敏感数据库，新人数据牢牢掌握在自己手中，同时提供丰富的默认真实新人案例数据（可一键重置）。
- **Decision 3: 音频策略与移动端兼容**
  - *Chosen Approach*: 采用 Web Audio API 与 HTML5 Audio 双重保障，首次用户点击开门封套时触发“用户激活手势”，完美突破 iOS Safari 与微信 WebView 的自动播放限制。
